# 轻量工作流版

当前分支只提供轻量工作流产品，不提供完整模式开关。范围依据 [ADR 0001](adr/0001-workflow-only-runtime.md)。

## 保留的能力

| 能力 | 说明 |
| --- | --- |
| 独立工作流 | 创建、列表、编辑、调试、发布、复制、执行及执行记录 |
| 基础节点 | 开始/结束、输入/输出、分支、循环/批处理、局部变量、文本和 JSON 处理 |
| HTTP、Python | 调用外部服务、执行 Python；继续使用原有代码执行器配置 |
| 大模型 | 模型管理、提示词、插件与子工作流工具调用 |
| 子工作流 | 调用独立工作流；子工作流也必须符合轻量版能力范围 |
| 数据库 | 数据库管理和 SQL、查询、插入、更新、删除节点 |
| 插件 | 插件管理、工具定义、调试、发布及插件节点 |
| 基础服务 | 账号、空间、文件上传、个人访问令牌和工作流 OpenAPI |

数据库节点操作平台管理的业务数据表；平台自身仍需要 MySQL 保存账号、工作流、插件和执行记录等数据。插件节点调用定义好的外部 API。

资源页分为工作流、插件、数据库三个分类，使用各自的数据库列表接口，保留名称查询与分页。没有跨资源类型的 Elasticsearch 检索。

插件管理列表仅显示当前用户拥有的插件；工作流插件选择器使用空间内已发布插件。草稿列表按登录用户过滤，不接受请求中伪造的开发者身份。

## 移除的运行依赖与能力

- Elasticsearch：统一资源检索及其异步索引更新。
- Milvus、etcd：知识库向量存储及相关基础设施。
- NSQ/RocketMQ：原有知识库处理和搜索索引事件链路。工作流异步执行继续使用原有进程内执行机制。
- 知识库/RAG：管理入口、读取/写入/删除节点，以及大模型知识库绑定。
- Agent/App、Chatflow：编辑入口、会话管理、会话节点、Agent/项目执行上下文和历史消息绑定。
- Agent/项目持久变量：全局变量读写；普通节点输出引用、循环内变量继续可用。
- 提示词资源库入口；大模型节点内直接编辑提示词继续可用。

旧业务源码、路由、生成客户端、页面和依赖已物理删除。已删除接口返回 404；资源变更不再投递搜索索引事件，也不保留空事件总线。已有数据库表、列和历史记录保留，新库仅初始化 23 张基础表，业务数据表按需创建。Docker 与 Helm 使用一致的初始化 SQL，启动不会自动执行破坏性 schema 对齐。

## 部署

默认 Docker Compose 仅启动 MySQL、Redis、MinIO、后端和前端，后两者从当前源码构建，避免运行上游完整版本镜像：

```bash
cp docker/.env.example docker/.env
make web
```

如已有 `docker/.env`，保留并检查其中的数据库、Redis、对象存储和模型配置。旧的 ES、MQ、向量库配置不再被启动链路使用。访问 `http://localhost:8888` 注册并进入工作流资源页；使用大模型节点前需配置模型。

开发环境：

```bash
make env
make middleware
make debug
```

`make middleware` 只启动三个中间件及其初始化任务。`make debug` 还构建前端、准备 Python 并启动后端，首次运行会下载依赖。

Helm 默认值和模板也已移除 ES、Milvus、etcd、RocketMQ。使用 Helm 前需构建当前分支镜像、推送到自己的镜像仓库，并覆盖 `cozeServer.image` 和 `cozeWeb.image`；默认标签为 `coze-workflow-server:local`、`coze-workflow-web:local`。

旧 OceanBase 向量库部署入口已移除；请使用上述 MySQL 部署入口。升级已有实例前先备份数据。裁剪不执行数据库删表，也不删除已有中间件的数据目录；旧容器需由部署维护者单独停止。

## 旧工作流兼容

保留已有工作流记录。含已移除节点、知识库绑定、会话历史、Agent/项目上下文或全局变量的工作流，在保存、发布或执行时返回明确错误；不会自动删节点后运行。子工作流执行同样校验。将不支持的节点或绑定移除后，可继续作为独立工作流使用。

大模型、外部 HTTP 和插件的实际调用仍需要有效模型配置、外部服务及对应凭证。轻量化不会替代这些外部依赖。
